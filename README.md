# Presence

An offline-first, privacy-focused college attendance companion built with React Native (Expo) and a Vercel serverless backend.

## Features
- **Accurate Attendance**: Direct synchronization with college ERP records.
- **Paper Theme**: Minimalist, tactile design inspired by classic stationery.
- **Privacy & Security**: Device-bound session tokens, rate limiting, and zero credential storage.
- **Offline First**: Instant startup with local storage and background synchronization.

## Tech Stack
- **Frontend**: React Native, Expo, React Navigation
- **Backend / API**: Vercel Serverless Functions (Node.js)
- **Database / Auth**: Firebase Firestore & Firebase Auth

## Getting Started

```bash
npm install
npx expo start
```

## Testing

```bash
npm test
```
